## 🚀 Open Source Projects

I enjoy building tools that make complex technologies easier to use, experiment with and extend.

### 🧩 [PyNode](https://github.com/olkham/pynode)
**Visual programming for Python, AI and computer vision.**

A Node-RED-inspired visual workflow editor with a Python backend. Build computer vision and AI pipelines by connecting nodes rather than writing endless boilerplate.

- Drag-and-drop visual workflow editor
- Python-based, extensible node architecture
- YOLO, OpenCV, tracking and vision-language models
- Real-time video processing and inference
- MQTT, TCP, UDP and REST integrations

### 📷 [IPyCam](https://github.com/olkham/IPyCam)
**A virtual IP camera written in Python.**

Simulate ONVIF-compatible IP cameras for developing, testing and integrating computer vision systems without needing physical camera hardware.

### 🎞️ [FrameSource](https://github.com/olkham/FrameSource)
**A flexible Python framework for video frame acquisition.**

A common interface for acquiring frames from different sources, making it easier to build camera-agnostic video processing applications.

### 📸 [pysonycam](https://github.com/olkham/pysonycam)
**Experimenting with Sony camera control through Python.**

Part of my ongoing interest in connecting photography, software and hardware.
